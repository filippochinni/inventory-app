# InventoryApp

InventoryApp is a stock management (inventory, stock, stocktaking) Android application which keeps track of the location of items and provides multiple features to help find, organize and visualize items.

### App Description

InventoryApp is an App specifically targeted to tidiness-addicts.
Being an organized, tidy and neat person is not always easy, it is hard to always remember where your overly-organized stuff is.

InventoryApp allows you to keep track of the location of your items. You can define a hierarchical disposition of you item.
